# docmost-teams v0.96.0

Rebased onto Docmost
[v0.96.0](https://github.com/docmost/docmost/releases/tag/v0.96.0)
(previously v0.95.0). See its release notes for upstream changes.

## What's new

- **No Enterprise code.** Upstream's Enterprise-licensed code is removed, the
  fork's screens are rewritten from a clean-room specification, and CI fails
  if Enterprise code comes back.
- **SSO presets** for Keycloak, Google, Microsoft Entra ID, Facebook and
  generic OIDC, with the redirect URI shown before saving and a connection
  test.
- **Group and role sync** follows nested claims and wildcard filters, and only
  removes memberships and roles it granted.
- **Safer SSO administration.** Only owners manage providers, a saved secret
  is only sent to its issuer, and the last provider can't be removed while SSO
  is enforced. An SSO sign-in that matches an unverified email ends that
  account's sessions and replaces its password.
- **Owners** can edit in every ordinary space, including in the real-time
  editor.
- **Private spaces** get a Home tab and can't be shared or published.
- **Migration scripts** move a database between Docmost and docmost-teams.
  See [Migrating](https://github.com/mesudip/docmost-teams/blob/v0.96.0/docs/migrating.md).

## Upgrade notes

- Back up the database. Migrations run on startup; the new trigram index on
  `pages` can take a while on large installs.
- Replace older images: they contained Enterprise-licensed code.
- Only workspace owners can change SSO providers.
- Group-sync providers from earlier builds keep their `Root` → owner rule,
  now shown in the provider form. New providers map no groups to roles.
- Upstream Enterprise features such as AI, API keys, audit logs, MFA, SCIM,
  templates, page permissions and PDF export aren't included.
- `.env.example` no longer contains a usable `APP_SECRET`; set your own.
- The image runs on Node 26.
