# docmost-teams v0.96.0

The first docmost-teams release that mirrors an upstream Docmost release. It
rebases docmost-teams onto Docmost
[v0.96.0](https://github.com/docmost/docmost/releases/tag/v0.96.0) (previously
v0.95.0) and carries the self-hosted features forward.

## From upstream Docmost v0.96.0

- Public spaces (beta): publish a whole space as public docs, with an optional
  `/docs` directory. Off by default; requires `BETA_PUBLIC_SPACES=true` and a
  workspace opt-in.
- Search: jump to search, enhanced search filters, and searching group members.
- Editor: footnotes, a lightbox for images and media, automatic RTL text
  direction, gap cursors between top-level blocks, and many smaller fixes.
- Pages: compare two page versions, a page attachments modal, and a fix for
  printing public pages.
- Collaboration upgraded to Hocuspocus v4, and a WebSocket relay fix.
- Redis URL parsing now supports ACL usernames, encoded credentials, empty
  passwords, missing ports, and TLS.
- The client is code-split and lazy-loaded.

## Fork features carried forward

- OIDC single sign-on with enforced SSO and group sync (`Root` group →
  workspace owner), implemented in `apps/server/src/teams/sso`.
- Private (personal) spaces, visible only to their direct members.
- Teams features unlocked for self-hosted installs.
- Multi-architecture container images published to GHCR.

## New in this release

- Releases now mirror upstream Docmost versions, and CI runs before any image
  is published.
- Personal spaces can't be published as public spaces. Anonymous public-space
  routes and public-space listings treat them as unpublished, and converting a
  space to personal also unpublishes it.

## Upgrade notes

- The container image now runs on Node 26, as upstream does.
- Four upstream database migrations run automatically on startup:
  `page-title-trgm-index`, `oauth`, `siem-destinations`, and `public-spaces`.
  The trigram index can take a while on large `pages` tables.
- Upstream Enterprise-only server features in v0.96.0 (SIEM, MCP OAuth, AI chat
  controls, the turbopuffer vector driver) aren't part of this build.
- `docker-compose.yml` now uses `ghcr.io/mesudip/docmost-teams:latest`.
- Back up the database before upgrading.
